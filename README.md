# AI Invoice + PayPal Pay Link

**PayPal AI Hackathon 2026** — Build what's next with PayPal and AI.

Freelancers lose time turning a plain-language job description into an invoice,
then chasing payment. This app does both in two clicks: **Gemini** turns the
description into invoice line items, and **PayPal Sandbox** turns the invoice
into a link the client can actually pay.

## How it works

1. Type who you are, who the client is, and what you did — in plain language.
2. Click **Generate invoice with AI**. Gemini (`gemini-3.5-flash`) returns
   structured line items (description, quantity, unit price) as JSON. Edit any
   line before continuing.
3. Click **Create PayPal payment link**. The server creates a PayPal Sandbox
   checkout order (`POST /v2/checkout/orders`, intent `CAPTURE`) for the exact
   invoice total and returns the approval link.
4. The client opens the link, approves in the PayPal Sandbox, and the app can
   check the order status (`GET /v2/checkout/orders/{id}`).

PayPal is not a mock: the order, the total and the approval link are all real
Sandbox objects. AI is not decoration: the invoice itself is generated by the
model, and the PayPal amount comes from what the model produced.

## Demo (2 minutes)

**Demo video:** https://youtu.be/SixxFBYIzCY

1. `cp .env.example .env` and fill in the three keys (see Setup).
2. `npm start` — open http://localhost:3000
3. Use the pre-filled example ("Designed a logo and a landing page…") and
   click **Generate invoice with AI**. Example output: logo $850, landing page
   $1,600, revisions 2 × $125 — total $2,700.
4. Click **Create PayPal payment link**, open the link, log in with a Sandbox
   buyer account, approve, then **Check order status**.

## Setup

No dependencies. Node 18+ only.

```bash
cp .env.example .env
npm start
```

Get the keys (both free, Sandbox only — no real money moves):

- **PayPal Sandbox:** developer.paypal.com → My Apps & Credentials →
  Sandbox → Create App. Copy the Client ID and Secret into `.env` as
  `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET`.
- **Gemini:** Google AI Studio (aistudio.google.com) → Get API key →
  Create API key. Copy it into `.env` as `GEMINI_API_KEY`. Free tier is enough.

`.env` is gitignored. Never commit keys.

## Project structure

```text
server.js            # HTTP server, Gemini + PayPal Sandbox calls, no dependencies
public/index.html    # Single-page UI: form, editable invoice, PayPal link, status check
.env.example         # The three keys the app needs, no values
README.md            # This file
LICENSE              # MIT
```

## API

- `GET /api/config` — whether PayPal and Gemini are configured (no secrets).
- `POST /api/generate` — `{seller, client, description, currency}` →
  `{items, notes, model}`.
- `POST /api/create-order` — `{items, currency, description, clientEmail}` →
  `{orderId, status, total, currency, approveUrl}`.
- `GET /api/order/:id` — `{orderId, status, payer}`.
